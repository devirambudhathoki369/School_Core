Calling the API

Sign in first

Each role signs in under /auth/. The session cookie it sets is what every other call is checked against.

Versions

The school API answers at /api/v1/ and /api/v2/. A bare /api/ is the same as v1.

Health check

/?format=json returns the status as JSON, with 503 when the database is down.
